# Authorized cases

Create a case folder only when requested and approved. Keep the brief, plan,
and reflection scoped to that case. Minimize identifying details and record
unknowns honestly. Approval to coach is not approval to save or send a case.

One Markdown case is enough. Use the [case template](../../case-record-template.md)
and [manual return workflow](../../../references/workflows/resume.md) when useful.
Keep proposals, agreed plans, actual attempts and outcomes distinct; reuse only
the actual permission granted for this case's updates. This folder is not a
conversation log or a profile of another person.

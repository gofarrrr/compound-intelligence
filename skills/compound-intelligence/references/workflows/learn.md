# Learn one useful move

**Book foundation:** GUIDE and Show and Explain, Chapter 13, pp. 194–211; Reflect, Repeat, Remind, pp. 333–334. This lesson structure and its assessment criteria are implementation design.

## Choose the learning target

Use the situation or topic the user names. Read the matching chapter card. When the user wants a general introduction, briefly introduce the three pillars and begin with a broadly useful distinction such as observation versus interpretation, unless their stated goal points elsewhere. Do not begin with a 21-chapter lecture or infer a deficiency from their choice.

State an observable objective: “By the end, you can turn a character judgment into factual feedback,” not “You will be a more intelligent leader.” Use one framework and a small amount of supporting explanation.

## Show, explain, practice

Explain the challenge the framework addresses and the source principle behind it. Show a short **original, hypothetical** example using only facts declared in that example. Contrast a common error with a better move. Explain exactly what changed and why; naming an acronym is not sufficient.

Ask the user for a small application or teach-back when an interactive lesson is appropriate. Do not force a question when the user asked for a complete lesson or reference document; include a self-check and a labeled sample answer instead.

Assess only observable features of the response: Does it separate facts from interpretations? Does it use a genuine question? Is autonomy real? Does the action fit the constraints? Give one specific strength and one useful correction when both exist. Do not invent praise or grade the user’s personality, intelligence, or potential.

Offer a second situation that changes one relevant condition. Ask when the framework would no longer be the best choice. This tests transfer instead of memorization. Let the user choose whether to continue.

## Leave a practice cue

End with one real-world opportunity, a cue for noticing it, and a simple reflection question. Suggest a reminder only as a proposal; do not claim it has been scheduled. Saving a practice preference or result requires the save workflow and the relevant authorization.

## Output

A compact lesson should contain the source framework and chapter, one worked example, the explanation of the move, one exercise or teach-back, and a self-check or next practice. Label example answers as demonstrations rather than evidence of successful real-world outcomes.

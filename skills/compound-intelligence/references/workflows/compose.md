# Compose a fit-for-purpose workflow

**Implementation architecture:** adapted from Compound Writing’s emergent composition pattern. Do not label the composition as a new Webb framework.

Read the actual request, materials, workspace rules, and available capabilities. Define the requested outcome and the parts that remain unresolved. Use a single chapter when it is enough. Use the routing guide to distinguish prerequisites rather than chaining every tool that has a keyword match.

Plan the smallest useful sequence. State the meaningful passes briefly, then begin with available evidence. Examples: understand conflicting accounts → prepare a factual feedback conversation; clarify a goal → remove change friction; stabilize a failure → investigate → reflect after actual results. These are conditional routes, not mandatory pipelines.

Keep each pass’s output useful to the next: an evidence map should inform the conversation; a decision criterion should govern an option comparison; a reflection should refer to the actual attempt. Avoid restarting context loading and asking the same questions at every handoff.

Use actual read/search/write capabilities only when needed and authorized. Do not claim missing features or spawn workers that do not exist. When access fails, name the specific blocked component, complete what the available evidence supports, and keep the limitation visible. Do not fill a missing source with generic advice while pretending it is source-derived.

For cross-case pattern analysis, inspect the authorized case records, distinguish different contexts, and look for disconfirming examples. Repetition across anecdotes can suggest a hypothesis; it does not establish causality or justify a universal rule. Proposed generalization goes through the save workflow.

Finish the requested outcome, including a concise coaching explanation of the key transition between tools. Report actual outputs and changes, material uncertainty, and any approved lesson. Do not create a new user-invokable skill, alter the installed package, or claim an improved model merely because a composition worked once.

# Worked examples

User inputs, dialogue and branches here are **original, hypothetical demonstrations** created for this package. They are not book quotations, records of the user, transcripts from a tested model run, or evidence that an intervention succeeded in practice. Source notes in the adaptive examples separately paraphrase Webb's teaching scenes and leader accounts; their limits remain explicit.

Read [applied coaching](applied-coaching.md) for three examples of route selection, practical advice, and teaching. Read [learning and rehearsal](learning-and-rehearsal.md) for the educational modes and [reflection and saving](reflection-and-saving.md) for the consent-based learning loop.

For a changed-information branch, a useful stopping point or a concise handoff, read the matching [adaptive coaching example](adaptive-coaching.md):

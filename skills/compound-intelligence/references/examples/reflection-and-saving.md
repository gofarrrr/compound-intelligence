**User:** “I tried the factual-feedback opening. The colleague explained that two teams had given conflicting priorities. We clarified the order, and the next handoff was on time. Save that asking first always fixes missed deadlines.”

“The conversation appears to have surfaced a priority conflict, and the next handoff was on time. That does not yet show that asking first always fixes deadlines. A narrower lesson is: ‘When a handoff fails, describe the event and impact, then ask about the conditions before concluding it is a motivation problem.’ This fits Factual Feedback, but the outcome could also reflect the clarified priority or other changes. May I save that narrower version as a provisional practice rule?”

This confirmation is needed because the proposed durable wording differs materially from the user’s original universal claim. The skill can also preserve the original observation as a scoped case note when the user authorizes that exact record.

**After the user approves the narrower rule and names an authorized file:** read the file, preserve its existing entries, and perform the narrow write using a real file tool. Only then report the destination and saved status.

## Example record content

Rule: Describe the missed handoff and its impact, then ask about conditions before inferring motivation.

Kind/status: Practice experiment / provisional.

Scope: A specific work handoff with an unexplained cause, not immediate safety incidents or a substitute for an existing formal process.

Source: Factual Feedback, Chapter 12; process/outcome distinction, Chapter 4.

Observation: In this hypothetical case, a priority conflict was identified and the next handoff occurred on time.

Limits: One case. The cause of improvement is not established. Clarified priorities or other changes may explain the result. This does not guarantee future compliance.

Review trigger: Another comparable handoff conversation, followed by a reflection. No reminder has been scheduled.

Approval: Explicit approval of the narrowed wording is required before persistence.

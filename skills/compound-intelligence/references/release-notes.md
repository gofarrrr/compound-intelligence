# Release 0.3.0 — 2026-10-06 — experimental preview

Adds a complete-folder installer, user-run Codex launcher and manual case return. Setup accepts your TypeSafe key only through your own process environment or a hidden terminal prompt, not chat. Installation refuses to overwrite an existing copy. The launcher starts a new Codex process, writes no key file and makes no TypeSafe call itself. A key is separate from provider consent; live connection testing and case/draft transfer remain explicitly approved. See [onboarding](onboarding.md).

The project/portable licenses cover original work under MIT, with third-party rights retained in NOTICE. No original book, personal case or credential is included. Package metadata is 0.3.0; decision runtime contracts remain ci.preflight.v2.0.0 / ci.postflight.v2.1.0, policy ci.policy.v2.0.0, strict > 0.25, G active and H unpromoted. Cards, questions, policy and revision limit remain unchanged.

This release tests an experience across time: prepare, try, return and compare. The earlier B/P study did not establish the required single-answer advantage. No real-user continuity value, calibration, human-review agreement or coaching effectiveness is claimed. E/C/D are not promoted as proven improvements. The prior G release record below retains the known bc-005, ua-010 and ua-011 limits.
